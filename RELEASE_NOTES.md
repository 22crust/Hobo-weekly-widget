Big updates
- Custom task lists: add, rename, hide, delete, reorder, and set default layouts (right click the tasks page).
- Addition of a free-text section in the tasks page.
- Space under the calendar has some tools you can toggle on and off (or option to hide all)

- If you can't find "Hobo weekly" in your apps, uninstall and reinstall from the latest update https://github.com/22crust/Hobo-weekly-widget/releases/tag/v1.4.0
